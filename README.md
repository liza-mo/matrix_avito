# Тестовое задание Авито, обход матрицы по спирали 

## Что это 
Решение тестового задания для стажеров от компании Авито на позицию Python-разработчик. 
Библиотека скачивает квадратную матрицу с сервера и возвращает список чисел, обходя матрицу по спирали против часовой стрелки.

**Ссылка на исходное задание**
https://github.com/avito-tech/python-trainee-assignment

## Что сделано
- Написана асинхронная функция `get_matrix`, которая скачивает данные по ссылке.
- Написан алгоритм обхода матрицы по спирали.
- Добавлена базовая защита от ошибок (если пропал интернет или сервер выдал ошибку, программа не падает, а пишет сообщение).
- Написан тест из задания для проверки результата.

## Что не сделано 
- Нет проверки на то, что матрица квадратная, так как в задании четко сказано, что матрица всегда вида (NxN)

## Как запустить 

Для запуска понадобится установленный Python 3.8+ и терминал.

**Шаг 1. Скачайте проект и перейдите в него**

    git clone https://github.com/liza-mo/matrix_avito.git
    cd matrix_avito

**Шаг 2. Создайте и активируйте виртуальное окружение** 

Для Mac/Linux:

    python3 -m venv venv
    source venv/bin/activate

Для Windows:

    python -m venv venv
    venv\Scripts\activate

*(После активации в начале строки терминала появится (venv))*

**Шаг 3. Установите зависимости**

    pip install aiohttp

**Шаг 4. Запустите тест**

    python test.py

**Что вы увидите в консоли:** 
Программа пошагово отобразит процесс работы (скачивание данных, поиск чисел, сборку матрицы и обход по спирали). В конце она выведет два списка — полученный результат и ожидаемый эталон. Если они совпадут, появится сообщение: 
"Тест пройден"
